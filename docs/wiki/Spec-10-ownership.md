## 引き継ぎに必要なもの

単独運用のリスクを下げるため、以下を第二の担当者と共有しておく。

| 項目 | 所在 | 備考 |
| --- | --- | --- |
| `terraform.tfvars` | 管理端末 (gitignore) | **これがないと apply できない**。秘密の全量が入っている |
| `terraform.tfstate` | 管理端末 (gitignore) | 失うと既存リソースを Terraform が見失う |
| SSH 秘密鍵 | 管理端末 `~/.ssh/oci_mc` | Tailscale SSH が主なので優先度は低い |
| OCI APIキー | 管理端末 `~/.oci/` | 再発行できる |
| 各サービスのログイン情報 | 上記アカウント表 | |

`terraform.tfvars` と `terraform.tfstate` は**リポジトリに入っていない**ため、管理端末が壊れると失われる。パスワードマネージャや暗号化したバックアップに退避しておくこと。

state を失った場合は `terraform import` で既存リソースを取り込み直すことになる。これを避けたい場合は OCI Resource Manager への移行を検討する ([06. 運用・保守](Spec-06-operations) の将来の拡張)。

## 判断の委譲範囲

| 判断 | 誰が決めるか |
| --- | --- |
| 友人の招待 / ホワイトリスト追加 | サーバー管理 (OP) |
| 権限グループの設計変更 | サーバー管理 (OP) |
| 閾値・監視間隔の調整 | 構築・運用 |
| `exposure_mode` の変更 | オーナー |
| Minecraft のメジャーバージョン更新 | オーナー (ワールド互換に影響するため) |
| VM の再作成 | オーナー (ワールド消失リスクがあるため) |
| 課金の発生する変更 | オーナー |
